⚠ No se pudo conectar con Google Drive El error "Failed to fetch" ocurre porque el navegador bloquea llamadas directas a la API de Google Drive cuando la app se abre como archivo local (file://). Para solucionarlo, la app necesita estar publicada en un servidor web.

✅ Solución más rápida — GitHub Pages (gratis):
  1. Ir a github.com → Crear cuenta o iniciar sesión
  2. Crear repositorio nuevo → marcar como Public
  3. Subir el archivo ordenanzas_concepcion.html
  4. Ir a Settings → Pages → Source: rama main
  5. La URL pública será: https://TU_USUARIO.github.io/REPO/ordenanzas_concepcion.html

✅ También verificar en Google Cloud Console:
  1. Ir a APIs y servicios → Credenciales
  2. Seleccionar la API Key → Restricciones de aplicaciones
  3. Elegir "Ninguna" o "Sitios web HTTP" y agregar el dominio donde se aloje la app
  4. Verificar que la Google Drive API esté habilitada en el proyecto
  5. Confirmar que la carpeta Drive esté compartida como "Cualquiera con el enlace puede ver"

Mientras tanto la app funciona con el catálogo de demostración con 30 ordenanzas de ejemplo.

Configuración — Google Drive y Chatbot IA

Pasos para obtener la API Key:

  1. Ingresar a console.cloud.google.com
  2. Crear o seleccionar un proyecto
  3. Ir a APIs y servicios → Credenciales
  4. Clic en Crear credenciales → Clave de API
  5. Restringir la clave a la Google Drive API
  6. Asegurarse que la carpeta de Drive sea pública (compartida como "Cualquiera con el enlace puede ver")

La clave se guarda solo en este navegador (localStorage). No se envía a ningún servidor externo.
